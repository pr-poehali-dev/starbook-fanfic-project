
# Структура данных проекта

Этот каталог содержит все файлы, связанные с данными приложения, включая тестовые данные и сервисы для работы с ними.

## Файлы и их назначение

### Основные файлы

- `fanfics.ts` - Главный файл, экспортирующий все функции и данные для работы с фанфиками (реэкспорты из других файлов)
- `constants.ts` - Константы для всего приложения (стандартные изображения, списки категорий и т.д.)
- `fandoms.ts` - Данные и функции для работы с фэндомами

### Данные и моки

- `mock-authors.ts` - Тестовые данные авторов
- `mock-fanfics.ts` - Тестовые данные фанфиков
- `featured-fanfics.ts` - Функции для получения рекомендуемых и популярных фанфиков

### Сервисы

- `fanfic-service.ts` - Функции для работы с фанфиками (поиск, фильтрация, получение)

## Порядок использования

1. Импортируйте все необходимые данные и функции из `fanfics.ts`:

```typescript
import { 
  fanfics, 
  getFanficById, 
  getFeaturedFanfics 
} from "@/data/fanfics";
```

2. Если вам нужны конкретные функции из одного модуля, вы можете импортировать их напрямую:

```typescript
import { searchFanfics } from "@/data/fanfic-service";
```

## Структура данных

Все типы данных определены в директории `src/types/`, где можно найти интерфейсы для:
- Fanfic - структура фанфика
- Author - структура автора
- Fandom - структура фэндома

## Расширение

При добавлении новых функций следуйте принципу единой ответственности:
1. Добавьте функцию в соответствующий файл сервиса
2. Реэкспортируйте её в основном файле `fanfics.ts`
